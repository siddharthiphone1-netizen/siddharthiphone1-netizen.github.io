Privacy policy

Last updated: 22 November 2026

Clip Studio is a personal tool used only by the owner of the OnlineGaming YouTube channel. This policy explains what data it handles when it connects to YouTube.

YouTube API Services

Clip Studio uses YouTube API Services. Data obtained through them is also handled under the Google Privacy Policy, and use of Clip Studio is subject to the YouTube Terms of Service.

What data Clip Studio accesses

With the channel owner’s permission, Clip Studio requests two YouTube permissions:

  • Upload videos (youtube.upload): to publish clips the owner has approved.
  • Manage the YouTube account (youtube): only to read the connected channel’s name, find or create playlists, and add uploaded clips to them.

It does not read comments, messages, subscribers, watch history, analytics or any other account data, and it never accesses anyone else’s account.

How data is stored

The access token Google issues is stored only on the owner’s private server, in a file readable by that server account alone. Clip titles, descriptions and upload links are stored in the same private database. Nothing is stored on third-party services.

Sharing

Clip Studio does not sell, share or transfer any data to anyone. Data is used only to upload the owner’s own clips to the owner’s own channel.

Retention and deletion

Data is kept only while the channel stays connected. Choosing Disconnect in Clip Studio deletes the stored token immediately. Access can also be revoked at any time on the Google security settings page. Stored clip details are deleted on request within 30 days.

Cookies

Clip Studio does not place cookies or trackers on anyone’s device.
